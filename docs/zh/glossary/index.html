中医术语词典

中医核心术语速查，含汉字与拼音。这些词贯穿全站内容，遇到不熟悉的词随时回来查阅。

术语 汉字 拼音 释义
气 氣 qì 推动人体生命活动的精微能量——消化、温煦、运动、防御，皆赖于气。
阴阳 陰陽 yīn yáng 万事万物互补的两面；健康即二者动态平衡。
五行 五行 wǔ xíng 木火土金水——关联脏腑、情志、季节与味道的动态模型。
脏腑 臟腑 zàng fǔ 主藏精气的五脏与主传化的六腑，构成功能网络。
经络 經絡 jīng luò 运行气血的通道，沟通脏腑与体表。
穴位 穴位 xué wèi 经络上气血输注、可从体表施加调节的特定位置。
穴位按压 穴位按壓 xué wèi àn yā 以指压代替针具刺激穴位的方法。
艾灸 艾灸 ài jiǔ 以燃烧的艾绒温煦穴位或部位。
血 血 xuè 濡养组织、濡养孔窍并安顿心神的赤色精华——内涵较现代「血液」更广。
津液 津液 jīn yè 体内一切起濡润作用的液体：唾液、汗液、泪液、关节滑液、黏膜分泌物。
精 精 jīng 藏于肾的先天储备，主宰生长发育、生殖与衰老。
神 神 shén 心所藏的精神活动之总称；外显为眼神、睡眠与临在感。
湿 濕 shī 一类重浊黏滞的病理状态：头重如裹、肢体困重、脘腹胀满、舌苔厚腻。
热 / 火 熱 / 火 rè / huǒ 亢盛的病理状态：口渴、红赤、烦扰不安、类炎症表现。
虚 虛 xū 生命物质的不足之证：疲乏、无力、面色少华。
瘀 / 滞 瘀 / 滯 yū / zhì 气或血的运行受阻：胀满、固定刺痛、郁怒、唇舌紫暗。
食疗 食療 shí liáo 利用日常食物的性与味，温和地纠正偏颇。
粥 粥 zhōu 慢火熬成的米粥，脾胃虚弱与病后调养的经典食物。
刮痧 刮痧 guā shā 以光滑器具刮拭皮肤，推动浅表气血运行。
拔罐 拔罐 bá guàn 以负压吸附于皮肤，引气血汇聚、松解浅表紧张。
